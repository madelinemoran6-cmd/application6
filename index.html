Madeline Moran Real Time Systems

In this assignment I developed a model of a real time system to align with Luminar Technologies LiDAR sensors and perception software for self-driving cars. My design includes two LEDs (one acting as a power symbol and one as an error symbol), a push button (acting as a manual break), and a potentiometer which acts as a sensor to measure distance. This project connects to WIFI using Wokwi to share real-time updates on the distance between the car and any other objects.
